# Get Export Table for Ranges

Generates an export table for range plots.

## Usage

``` r
getExportTableForRanges(plotObject, aggregationFun, xLabel)
```

## Arguments

- plotObject:

  A plot object generated from the plotting functions.

- aggregationFun:

  A function for aggregating the data for exporting.

- xLabel:

  A label for the x-axis.

## Value

A data.table containing the export data for range plots.
