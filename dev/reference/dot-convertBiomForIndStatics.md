# Convert Biometrics for Individual Statistics

This function converts biometrics data for individual statistics into a
specific format.

## Usage

``` r
.convertBiomForIndStatics(biomForInd, sim)
```

## Arguments

- biomForInd:

  A data.table containing biometrics for an individual.

- sim:

  A simulation object.

## Value

A data.table with converted biometrics.
