# Set Plot Tag

Assigns plot tags to the data for plotting.

## Usage

``` r
setPlotTag(plotData, asRangePlot, usePKParameter)
```

## Arguments

- plotData:

  A data.table containing the plot data.

- asRangePlot:

  Logical indicating if the plot is a range plot.

- usePKParameter:

  Logical indicating if PK parameters are to be used.

## Value

A data.table containing the updated plot data with assigned plot tags.
