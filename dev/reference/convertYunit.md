# Convert Y Unit

This function converts the y-values of a time profile based on unit
conversion factors.

## Usage

``` r
convertYunit(timeprofile, dtUnit)
```

## Arguments

- timeprofile:

  A data.table containing time profile data.

- dtUnit:

  A data.table with unit conversion factors.

## Value

A data.table with the y-values converted to the target unit.
