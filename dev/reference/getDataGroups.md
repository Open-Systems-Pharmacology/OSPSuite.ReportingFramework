# Load the Properties for Data Groups

This function loads the properties for data groups from the specified
workbook.

## Usage

``` r
getDataGroups(wbPlots)
```

## Arguments

- wbPlots:

  The path to the workbook containing the data groups.

## Value

A \`data.table\` with data group IDs.
