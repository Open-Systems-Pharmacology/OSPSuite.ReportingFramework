# Validate Common Inputs

Validates common inputs for PK forest plotting functions.

## Usage

``` r
validateCommonInputs(
  pkParameterDT,
  dataObservedPK,
  scaleVectors,
  labelWrapWidth,
  vlineIntercept
)
```

## Arguments

- pkParameterDT:

  Data table containing PK parameter data.

- dataObservedPK:

  Optional data table for observed PK parameters.

- scaleVectors:

  A list defining colors, fills, and shapes for the plot.

- labelWrapWidth:

  Width for wrapping labels.

- vlineIntercept:

  Optional vertical line intercept.

## Value

NULL (invisible).
