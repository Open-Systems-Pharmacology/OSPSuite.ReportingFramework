# Adjust PK Forest Plot Object

Adjusts aesthetics of the PK forest plot object.

## Usage

``` r
adjustPkForestPlotObject(
  combinedObject,
  scaleVectors,
  vlineIntercept,
  tableLabels
)
```

## Arguments

- combinedObject:

  The plot object to adjust.

- scaleVectors:

  A list defining colors, fills, and shapes for the plot.

- vlineIntercept:

  Optional vertical line intercept.

- tableLabels:

  named vector with table headers

## Value

The adjusted plot object.
