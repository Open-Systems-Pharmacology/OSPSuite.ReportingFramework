# Validate PK Forest Absolute Values with Variance Configuration

Validates the configuration for PK forest plots with absolute values and
variance.

## Usage

``` r
validatePKForestAggregatedAbsoluteValuesConfig(configTable, pkParameterDT, ...)
```

## Arguments

- configTable:

  A data.table containing the configuration table.

- pkParameterDT:

  A data.table containing PK parameter data.

- ...:

  Additional arguments for validation.

## Value

NULL (invisible).
