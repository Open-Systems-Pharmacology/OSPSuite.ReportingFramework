# Validate PK Forest Configuration Table

Validates the configuration table for PK forest plots.

## Usage

``` r
validatePKForestConfigTable(configTable, pkParameterDT, ...)
```

## Arguments

- configTable:

  A data.table containing the configuration table.

- pkParameterDT:

  A data.table containing PK parameter data.

- ...:

  Additional arguments for validation.

## Value

NULL (invisible).
