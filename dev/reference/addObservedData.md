# Add Observed Data to Plot Data

This function adds the observed data to the plot data.

## Usage

``` r
addObservedData(plotData, dataObservedPK, onePlotConfig)
```

## Arguments

- plotData:

  Data table with calculated plot data.

- dataObservedPK:

  Optional data table for observed PK parameters.

- onePlotConfig:

  Configuration for the plot.

## Value

Updated plot data with observed data added.
