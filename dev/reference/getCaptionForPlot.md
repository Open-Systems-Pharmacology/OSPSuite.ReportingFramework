# Generate a caption for the plot

Generate a caption for the plot

## Usage

``` r
getCaptionForPlot(plotData, yScale, timeRangeFilter, plotType, plotCounter)
```

## Arguments

- plotData:

  Object containing the data for the plot.

- yScale:

  Y scale of the plot.

- timeRangeFilter:

  Name of the time range filter.

- plotType:

  Type of the plot.

- plotCounter:

  counter of plot

## Value

Caption text for the plot.
