# mdHeading Insert heading with specified level (1-6).

mdHeading Insert heading with specified level (1-6).

## Usage

``` r
mdHeading(..., level = 1, newlines = 2)
```

## Arguments

- ...:

  Content passed to mdPaste.

- level:

  Header level (default 1).

- newlines:

  Newlines after heading (default 2).

## Value

Invisible \`NULL\`.
