# Add Demographics to Bin

Adds demographic data to bins for plotting.

## Usage

``` r
addDemographicsToBin(
  plotData = plotData,
  onePlotConfig = onePlotConfig,
  scenarioList = scenarioList
)
```

## Arguments

- plotData:

  A data.table containing the plot data.

- onePlotConfig:

  A configuration for the specific plot.

- scenarioList:

  A list of scenarios to consider.

## Value

A data.table containing the updated plot data with demographic bins.
