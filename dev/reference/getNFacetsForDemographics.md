# Get Number of Facets for Demographics

Determines the number of facets to use for demographic plots.

## Usage

``` r
getNFacetsForDemographics(idData, isRangePlot, nMaxFacetRows = 2)
```

## Arguments

- idData:

  A data.table containing the plot data.

- isRangePlot:

  Logical indicating if the plot is a range plot.

- nMaxFacetRows:

  Maximum number of facet rows (default is 2).

## Value

The number of facet columns to use.
