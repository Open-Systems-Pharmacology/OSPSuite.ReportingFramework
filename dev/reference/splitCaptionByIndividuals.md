# Split Caption by Individuals

This function splits the caption data by individual IDs.

## Usage

``` r
splitCaptionByIndividuals(configTable, individualIdVector, dtCaption)
```

## Arguments

- configTable:

  A data frame containing the configuration data.

- individualIdVector:

  A vector of individual IDs.

- dtCaption:

  A data table containing the caption data.

## Value

A data table with merged caption data by individuals.
