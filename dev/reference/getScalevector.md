# Returns a Scale Vector Usable for Manual Scaling in ggplot

Returns a Scale Vector Usable for Manual Scaling in ggplot

## Usage

``` r
getScalevector(namesOfScaleVector, listOfValues)
```

## Arguments

- namesOfScaleVector:

  Names of the vector.

- listOfValues:

  List of possible entries. Takes the first where all values are not NA.

## Value

A scale vector.
