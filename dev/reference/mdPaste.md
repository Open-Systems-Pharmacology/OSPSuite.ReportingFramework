# mdPaste

mdPaste

## Usage

``` r
mdPaste(..., sep = " ", collapse = NULL, newlines = 1)
```

## Arguments

- ...:

  Elements to be \`paste\`d.

- sep:

  Separator (default \`" "\`).

- collapse:

  Collapse argument.

- newlines:

  Newlines afterwards (default 1).

## Value

Invisible \`NULL\`.
