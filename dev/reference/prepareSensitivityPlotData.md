# Prepare Sensitivity Plot Data

Prepares the data required for creating a sensitivity plot based on the
provided configuration.

## Usage

``` r
prepareSensitivityPlotData(onePlotConfig, projectConfiguration, scenarioList)
```

## Arguments

- onePlotConfig:

  A data frame containing the configuration for a single plot.

- projectConfiguration:

  A list containing project configuration settings.

- scenarioList:

  A list of scenarios for which the sensitivity analysis will be
  performed.

## Value

A data table containing the prepared data for the sensitivity plot.
