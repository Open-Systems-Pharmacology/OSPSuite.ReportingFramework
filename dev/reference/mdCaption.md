# Add caption with optional custom style.

Add caption with optional custom style.

## Usage

``` r
mdCaption(subfolder, captionFile, captionPrefix, captionStyle = NULL)
```

## Arguments

- subfolder:

  Folder location.

- captionFile:

  Caption file.

- captionPrefix:

  Prefix (e.g., "Figure 1:").

- captionStyle:

  Custom style (optional).

## Value

Invisible \`NULL\`.
