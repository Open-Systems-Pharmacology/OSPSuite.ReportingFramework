# Process Individual

This function processes individual data and generates as results a list
of all parameters transferred to population csv

## Usage

``` r
.processIndividual(individual, biomForInd, params, projectConfiguration, sim)
```

## Arguments

- individual:

  An individual object.

- biomForInd:

  A data.table containing biometrics for an individual.

- params:

  A list of parameters for the virtual twin population.

- projectConfiguration:

  A list containing project configuration details.

- sim:

  A simulation object.

## Value

A list of results for the individual.
