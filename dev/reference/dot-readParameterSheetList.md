# Read Parameter Sheet List

This function reads parameters from specified sheets in an Excel file.

## Usage

``` r
.readParameterSheetList(projectConfiguration, dtTwinPops, sim)
```

## Arguments

- projectConfiguration:

  A list containing project configuration details.

- dtTwinPops:

  A data.table containing virtual twin population data.

- sim:

  A simulation object.

## Value

A list of parameters for the specified sheets.
