# Insert bulleted item with indentation.

Insert bulleted item with indentation.

Insert bulleted item using paste0.

## Usage

``` r
mdBullet(..., bullet = "-", level = 1)

mdBullet0(..., bullet = "-", level = 1)
```

## Arguments

- ...:

  Bullet content.

- bullet:

  Bullet character (default "-").

- level:

  Indentation level (default 1).

## Value

Invisible \`NULL\`.

Invisible \`NULL\`.
