# Concatenate Text Vector with Commas and "and"

This function takes a vector of text strings and concatenates them into
a single string. For vectors with more than two elements, it separates
them with commas and uses "and" before the last element.

## Usage

``` r
concatWithAnd(textVector)
```

## Arguments

- textVector:

  A character vector of text strings to be concatenated.

## Value

A single character string representing the concatenated text.
