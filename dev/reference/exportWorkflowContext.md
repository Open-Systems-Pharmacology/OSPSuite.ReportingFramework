# Export workflow context for AI tools

Collects a compact, structured summary of key workflow configuration
tables. The output can be used directly by AI assistants to reduce
manual prompt setup.

## Usage

``` r
exportWorkflowContext(
  projectConfiguration,
  file = "workflow-context.json",
  includeNumericValues = TRUE
)
```

## Arguments

- projectConfiguration:

  Project configuration object.

- file:

  Optional output path for JSON export. If \`NULL\`, no file is written.

- includeNumericValues:

  If \`TRUE\`, include values imported via \`dataClassType =
  "numericValues"\` when available.

## Value

A named list with workflow context information.

## Details

Experimental: this helper is intended for early evaluation and may
change in future releases.
