# Insert markdown link.

Insert markdown link.

## Usage

``` r
mdLink(label, filename, folder, prefix = "")
```

## Arguments

- label:

  Link display text.

- filename:

  File to link to.

- folder:

  Folder location.

- prefix:

  Optional prefix (default "").

## Value

Invisible \`NULL\`.
