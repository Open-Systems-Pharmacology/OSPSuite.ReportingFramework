# Check and adjust Y limits for plots

Check and adjust Y limits for plots

## Usage

``` r
checkAndAdjustYlimits(plotData, yScale, timeRangeFilter, plotType, plotCounter)
```

## Arguments

- plotData:

  Object of class \`PlotDataTimeProfile\`.

- yScale:

  Y scale of the plot.

- timeRangeFilter:

  Name of the time range filter.

- plotType:

  Type of the plot.

## Value

Numeric vector of Y limits.
