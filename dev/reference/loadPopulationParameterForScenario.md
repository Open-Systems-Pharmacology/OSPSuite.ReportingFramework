# Load Population Parameter for Scenario

Loads population parameters for a specific scenario.

## Usage

``` r
loadPopulationParameterForScenario(
  scenarioName,
  scenarioList,
  onePlotConfigIdentifier
)
```

## Arguments

- scenarioName:

  The name of the scenario.

- scenarioList:

  A list of scenarios to consider.

- onePlotConfigIdentifier:

  A configuration identifier for the plot.

## Value

A data.table containing the loaded population parameters.
