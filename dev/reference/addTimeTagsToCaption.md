# Add Time Tags to Caption

This function adds time tags to the caption data based on the specified
time tags.

## Usage

``` r
addTimeTagsToCaption(dtCaption, timeTags, splitPlotsPerTimeRange)
```

## Arguments

- dtCaption:

  A data table containing the caption data.

- timeTags:

  A vector of time tags to be added.

- splitPlotsPerTimeRange:

  Boolean, if TRUE for each Time-range a plot is created

## Value

A data table with added time tags.
