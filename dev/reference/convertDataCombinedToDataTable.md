# Converts object of class \`DataCombined\` to data.table with attributes.

Format corresponds to \`data.table\` produced by
\`readObservedDataByDictionary\`.

## Usage

``` r
convertDataCombinedToDataTable(datacombined)
```

## Arguments

- datacombined:

  The input \`DataCombined\` object.

## Value

A \`data.table\` containing the converted data.
