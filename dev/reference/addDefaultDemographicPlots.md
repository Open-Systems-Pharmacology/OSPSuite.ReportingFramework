# Add Default Configuration for Pediatric Demography Plots

Adds default configurations for Pediatric demography plots to the
\`Plots.xlsx\` configuration file.

## Usage

``` r
addDefaultDemographicPlots(
  projectConfiguration,
  pkParameterDT,
  sheetName,
  overwrite,
  asRangePlot,
  templateSheet
)
```

## Arguments

- projectConfiguration:

  A ProjectConfiguration object.

- sheetName:

  Name of the sheet to create.

- overwrite:

  Logical indicating if existing data should be overwritten.

- templateSheet:

  Name of templateSheet in Configuration table

## Value

NULL (invisible).
