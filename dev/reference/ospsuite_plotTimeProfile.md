# Creates a time profile plot for given data.

This function generates a time profile plot using ggplot2, where the
data is grouped by a column named "group".

## Usage

``` r
ospsuite_plotTimeProfile(
  plotData,
  metaData = NULL,
  mapping = ggplot2::aes(),
  observedMapping = mapping,
  ...
)
```

## Arguments

- plotData:

  An object of class DataCombined or a data.frame generated by a
  DataCombined object. It is essential that the units are consistent; if
  not, use \`convertUnits(myDataCombined)\` to standardize.

- metaData:

  A list containing metadata for the plot. If NULL, a default list is
  constructed from the data.

- mapping:

  additional mappings specified by user

- observedMapping:

  Aesthetic mappings for the observed data, typically created with
  \`ggplot2::aes()\`.

- ...:

  Additional arguments passed to \`ospsuite.plots::plotTimeProfile\`.

## Value

A \`ggplot2\` plot object representing the time profile.

## Examples

``` r
if (FALSE) { # \dontrun{
# Generate a time profile plot for the provided data
plotTimeProfile(convertUnits(
  myDataCombined,
  xUnit = ospUnits$Time$h,
  yUnit = ospUnits$`Concentration [mass]`$`µg/l`
))
} # }
```
