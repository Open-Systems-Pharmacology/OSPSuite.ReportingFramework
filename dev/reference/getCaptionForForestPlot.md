# Get Caption for Forest Plot

Generates a caption for the forest plot based on the provided data.

## Usage

``` r
getCaptionForForestPlot(plotData, xScale, plotCaptionAddon, ratioMode)
```

## Arguments

- plotData:

  Data table containing plot data.

- xScale:

  Scale of the x-axis.

- plotCaptionAddon:

  Additional caption text.

- ratioMode:

  Mode for ratio calculations.

## Value

A string containing the caption for the plot.
