# Add Descriptions to Plot Data

This function adds descriptions to the plot data.

## Usage

``` r
addDescriptions(plotData, onePlotConfig, pkParameterDT)
```

## Arguments

- plotData:

  Data table with calculated plot data.

- onePlotConfig:

  Configuration for the plot.

- pkParameterDT:

  Data table containing PK parameter data.

## Value

Updated plot data with descriptions added.
