# Get Application Times

This helper function prepares the time range filter for application
times based on output paths and simulation results.

## Usage

``` r
getApplicationTimes(outputPathsPerScenario, simulatedResults)
```

## Arguments

- outputPathsPerScenario:

  A named list of output paths for each scenario.

- simulatedResults:

  List with simulation results

## Value

A list containing the start and end times of applications for each
scenario.
