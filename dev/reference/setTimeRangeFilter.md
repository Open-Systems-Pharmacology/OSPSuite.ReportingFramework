# Set Time Range Filter

This function sets the time range filter based on the facet type and
time tags.

## Usage

``` r
setTimeRangeFilter(splitPlotsPerTimeRange, timeTags)
```

## Arguments

- splitPlotsPerTimeRange:

  Boolean, if TRUE for each time-range a plot is created

- timeTags:

  A vector of time tags.

## Value

A list of time range filters.
