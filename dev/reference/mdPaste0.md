# mdPaste0

\`cat\` text using \`paste0\` and optionally end with newlines.

## Usage

``` r
mdPaste0(..., collapse = NULL, newlines = 1)
```

## Arguments

- ...:

  Elements to be \`paste0\`d.

- collapse:

  Passed to \`paste0\`. Defaults to \`NULL\`.

- newlines:

  Number of newlines to insert afterwards. Defaults to 1.
