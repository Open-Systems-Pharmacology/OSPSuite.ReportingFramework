# mdPaste0

mdPaste0

## Usage

``` r
mdPaste0(..., collapse = NULL, newlines = 1)
```

## Arguments

- ...:

  Elements to be \`paste0\`d.

- collapse:

  Collapse argument.

- newlines:

  Newlines afterwards (default 1).

## Value

Invisible \`NULL\`.
