# Build Virtual Twin Population

This function builds an virtual twin population table based on the
provided parameters and population data.

## Usage

``` r
.buildVirtualTwinPopulation(projectConfiguration, params, dPop)
```

## Arguments

- projectConfiguration:

  A list containing project configuration details.

- params:

  A list of parameters for the virtual twin population.

- dPop:

  A data.table containing population data.

## Value

A data.table representing the virtual twin population.
