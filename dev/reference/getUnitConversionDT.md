# Get Unit Conversion Data Table

This function creates a data table for unit conversion based on
simulated data and output specifications.

## Usage

``` r
getUnitConversionDT(dtSimulated, dtOutputs)
```

## Arguments

- dtSimulated:

  A data.table containing simulated results.

- dtOutputs:

  A data.table containing output specifications.

## Value

A data.table with unit conversion factors and unique paths.
