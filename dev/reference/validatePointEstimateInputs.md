# Validate Bootstrapping Inputs

Validates the inputs for bootstrapping in PK forest plots.

## Usage

``` r
validatePointEstimateInputs(nBootstrap, confLevel, statFun)
```

## Arguments

- nBootstrap:

  Number of bootstrap samples.

- confLevel:

  Confidence level for intervals.

- statFun:

  Statistical function for bootstrapping.

## Value

NULL (invisible).
