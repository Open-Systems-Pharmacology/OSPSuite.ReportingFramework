# Add meta data to a data set

Add meta data to a data set

## Usage

``` r
addMetaDataToDataSet(dataSet, groupData)
```

## Arguments

- dataSet:

  A \`DataSet\` object with observed data.

- groupData:

  Corresponding \`data.table\` with meta data.

## Value

A \`DataSet\` with observed data with added metadata.
