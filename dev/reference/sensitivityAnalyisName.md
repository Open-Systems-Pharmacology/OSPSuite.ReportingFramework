# Generate Sensitivity Analysis Output File Name

This function generates a name for the sensitivity analysis output file
based on the scenario name and sheet name.

## Usage

``` r
sensitivityAnalyisName(scenarioName, sensitivitysheet)
```

## Arguments

- scenarioName:

  The name of the scenario.

- sensitivitysheet:

  The name of the sensitivity sheet.

## Value

A string representing the generated file name for the sensitivity
analysis results.
