# Load the Output Configurations

This function loads the output configurations from the specified
workbook.

## Usage

``` r
getOutputPathIds(wbPlots)
```

## Arguments

- wbPlots:

  The path to the workbook containing the output configurations.

## Value

A \`data.table\` with output configurations.
