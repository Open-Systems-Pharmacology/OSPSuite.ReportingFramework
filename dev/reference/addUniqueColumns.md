# Add all columns of \`dataObserved\` which are unique for a group

Add all columns of \`dataObserved\` which are unique for a group

## Usage

``` r
addUniqueColumns(dataObserved, aggregatedData)
```

## Arguments

- dataObserved:

  The observed data.

- aggregatedData:

  The aggregated data.

## Value

The updated aggregated data as a \`data.table\`.
