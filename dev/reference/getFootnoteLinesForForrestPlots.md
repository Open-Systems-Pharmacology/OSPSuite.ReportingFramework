# Get Footnote Lines for Forest Plots

Generates footnote lines for the forest plot.

## Usage

``` r
getFootnoteLinesForForrestPlots(
  plotData,
  ratioMode,
  asPointeEstimate,
  dtDataReference
)
```

## Arguments

- plotData:

  Data table containing plot data.

- ratioMode:

  Mode for ratio calculations.

- asPointeEstimate:

  Logical indicating if confidence intervals should be calculated.

- dtDataReference:

  Optional data reference.

## Value

A character vector containing footnote lines.
