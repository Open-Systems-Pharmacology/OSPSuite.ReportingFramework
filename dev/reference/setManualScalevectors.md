# Set manual scale vectors for plots

Set manual scale vectors for plots

## Usage

``` r
setManualScalevectors(plotObject, plotData, plotType)
```

## Arguments

- plotObject:

  The ggplot object to update.

- plotData:

  Object containing the data for the plot.

- plotType:

  Type of the plot.

## Value

Updated ggplot object with manual scale vectors.
