# Get Observed Unit Conversion Data Table

This function retrieves the unit conversion data table for observed
data.

## Usage

``` r
getObservedUnitConversionDT(dataObserved, dtUnit)
```

## Arguments

- dataObserved:

  A data frame containing observed data.

- dtUnit:

  A data table containing unit information.

## Value

A data table with unit conversions for observed data.
