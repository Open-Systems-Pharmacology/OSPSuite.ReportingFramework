# validates common inputs for \`mdFigure\` and \`mdTable\`

Include a figure file with caption

## Usage

``` r
validateMdFigureTableInputs(subfolder, importFile, captionFile, customStyles)
```

## Arguments

- subfolder:

  The folder where the file is located relative to Rmd

- importFile:

  figure file or table .csv file

- captionFile:

  file containing caption

- customStyles:

  list of custom styles usable for figure and table captions and
  footnotes
