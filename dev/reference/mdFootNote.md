# Add footnote lines from file.

Add footnote lines from file.

## Usage

``` r
mdFootNote(subfolder, footNoteFile, footNoteCustomStyle = NULL)
```

## Arguments

- subfolder:

  Folder location.

- footNoteFile:

  Footnote file.

- footNoteCustomStyle:

  Custom style (optional).

## Value

Invisible \`NULL\`.
