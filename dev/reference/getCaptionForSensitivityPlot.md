# Get Caption for Sensitivity Plot

Generates a caption for the sensitivity plot based on the plot data and
project configuration.

## Usage

``` r
getCaptionForSensitivityPlot(plotData, projectConfiguration, plotCaptionAddon)
```

## Arguments

- plotData:

  A data table containing the data for the sensitivity plot.

- projectConfiguration:

  A list containing project configuration settings.

- plotCaptionAddon:

  An optional string to be added to the caption.

## Value

A string containing the generated caption for the sensitivity plot.
