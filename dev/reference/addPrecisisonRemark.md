# Add Precision Remark to Plot

Add Precision Remark to Plot

## Usage

``` r
addPrecisisonRemark(combinedObject, asPointeEstimate, plotData)
```

## Arguments

- combinedObject:

  The plot object to adjust.

- asPointeEstimate:

  Logical indicating if confidence intervals should be calculated.

- plotData:

  Data table containing plot data.

## Value

The adjusted plot object with precision remark if applicable.
