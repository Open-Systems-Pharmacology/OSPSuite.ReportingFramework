# Convert data by dictionary

This function converts the data based on the provided dictionary and
filters.

## Usage

``` r
convertDataByDictionary(data, dataFilter, dict, dictionaryName)
```

## Arguments

- data:

  The data to be converted.

- dataFilter:

  The filter to be applied to the data.

- dict:

  The dictionary to be used for conversion.

- dictionaryName:

  The name of the dictionary.

## Value

A \`data.table\` containing the converted data.
